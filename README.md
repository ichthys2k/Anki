# Anki-Pakete Französisch – Unité 1, Volet 3

Fertige Pakete (in Anki per Doppelklick bzw. *Datei → Importieren*) im Ordner [`dist/`](dist):

| Paket | Inhalt |
|---|---|
| `Franzoesisch_Unite1_Volet3_Vokabeln.apkg` | 19 Vokabeln (entre, il y a, la gare, le magasin, la boulangerie, …) mit Lautschrift, Genus, Beispielsatz, Merkhilfe und Bild. Je Vokabel FR→DE, DE→FR und (falls Bild) Bild→Wort = 51 Karten |
| `Franzoesisch_Unite1_Volet3_Wissen.apkg` | 17 Frage/Antwort-Karten zu Grammatik (un/une/des, Verneinung), Aussprache (Nasalvokale), Genus, Landeskunde (Baguette, Notre-Dame, Gare du Nord, …) und falschen Freunden |

Neu bauen: `pip install genanki pillow && python3 build_decks.py`
(Inhalte in `content.py`, eigene Illustrationen via `tools/make_illustrations.py`).
